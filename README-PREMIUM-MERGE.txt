KÁRPÁTALJA ATLASZ – PREMIUM MERGE
====================================
Ez a csomag az eredeti PROFESSIONAL-42 működő projektet tartja meg, és arra helyezi rá az egységes prémium zöld-fehér vizuális réteget.

Megőrzött alap:
- meglévő térképmotor
- meglévő GeoJSON/KML/SHP logika
- georeferálás
- rétegkezelő és szerkesztő fájlok
- magyar/ukrán oldalak
- admin és konfigurációs struktúra

Új:
- frontend/css/premium-unified.css
- frontend/css/layer-workspace-premium.css
- minden frontend oldalhoz bekötve
- a térképes oldalak fejléc/navigáció/map-header megjelenése is egységesítve

A funkciókhoz nem nyúltunk destruktívan: a dizájn külön CSS rétegben van, így később könnyen finomítható.
